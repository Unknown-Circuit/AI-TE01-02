# Flight Booking Agent (Expert System)

Modul ini menyediakan sistem pemesanan tiket penerbangan berbasis basis pengetahuan (*knowledge base*) dan aturan interaktif.

## 📄 Berkas dalam Folder

- **`app.py`**: Aplikasi antarmuka utama (Streamlit / CLI).
- **`flight_booking_core.py`**: Mesin inferensi (*inference engine*) dan aturan bisnis pemesanan.
- **`flight_knowledge_base.py`**: Data lokal mengenai jadwal, maskapai, bandara, dan harga tiket.
- **`project_report_Version1.md`**: Laporan dokumentasi teknis sistem pakar pemesanan penerbangan.
- **`requirements.txt`**: Daftar pustaka Python yang dibutuhkan.

## 🚀 Jalankan Aplikasi

```bash
pip install -r requirements.txt
python app.py
```
