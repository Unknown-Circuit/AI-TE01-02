# Laporan Proyek: Flight Booking Expert System (v1.0)

## 1. Pendahuluan
Sistem Pakar Pemesanan Tiket Pesawat dirancang untuk membantu pengguna dalam memfilter dan memilih jadwal penerbangan berdasarkan preferensi rute, budget, serta aturan maskapai.

## 2. Arsitektur Sistem
- **Knowledge Base**: Menyimpan data statis penerbangan dan preferensi rute.
- **Inference Engine**: Mengeksekusi pencocokan aturan rute dan kriteria filter pengguna.
- **User Interface**: Antarmuka interaktif CLI/Web.
