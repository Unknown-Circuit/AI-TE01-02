# Multi-Agent Flight Booking System

Sistem Multi-Agen terdistribusi di mana agen AI mandiri saling berkomunikasi untuk merencanakan dan merampungkan pemesanan tiket pesawat.

## 📄 Berkas dalam Folder

- **`main.py`**: Mengontrol alur interaksi dan komunikasi antar-agen.
- **`planner_agent.py`**: Agen yang menganalisis rute terbaik berdasarkan anggaran dan preferensi.
- **`booking_agent.py`**: Agen yang mengeksekusi konfirmasi dan transaksi tiket.

## 🚀 Jalankan Multi-Agent System

```bash
python main.py
```
